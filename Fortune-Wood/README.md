Fortune Wood (NeoForge 1.21.1)

Axes accept the Fortune enchantment (enchanting table, anvil, books). When you break a log with a fortune axe you get the normal drop plus bonus logs: woodPerLevel * (level + random 0..level). With the default woodPerLevel of 1: Fortune I +1-2, III +3-6, V +5-10, X +10-20. Tune it in config/fortunewood-common.toml.
